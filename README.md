# 🔦 스포트라이트 영상 생성기

이미지를 올리면 화면을 어둡게 덮고, 원형 스포트라이트가 이미지 위를 움직이는 영상을 만들어 주는 웹 툴입니다.
설치 없이 `index.html` 하나로 동작하고, 이미지는 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용법

1. **이미지 업로드**
2. 경로 방식 선택
   - 👆 **점 찍기**: 이미지를 클릭한 순서대로 스포트라이트가 이동해요. 원 안쪽 드래그로 이동, 우측 하단 흰 점 드래그로 크기 조절.
   - ✏️ **직접 그리기**: 드래그로 경로를 그립니다. "그린 속도 그대로 반영"을 켜면 그린 속도대로, 끄면 일정한 속도로 움직입니다.
   - 📜 **위→아래 훑기**: 이미지를 위에서 아래로 지그재그로 훑습니다.
3. 이동 속도, 어두움, 원 크기, 경계 부드러움, 마지막 효과를 설정
4. **▶ 미리보기**로 확인하고, **● 녹화 시작**으로 영상 저장

### 마지막 효과
기본(그대로 멈춤) / 확대하며 전체 공개 / 서서히 밝아짐 / 페이드 아웃 / 줌인 / 원이 닫히며 끝

## 참고
- 영상 저장은 브라우저의 `MediaRecorder`를 사용합니다. 최신 크롬/사파리/엣지에서는 **mp4**로 저장되고, 지원하지 않는 브라우저(예: 일부 파이어폭스)에서는 **webm**으로 저장됩니다. (webm은 변환 사이트에서 mp4로 바꿀 수 있습니다)
- 녹화하는 동안에는 탭을 바꾸지 마세요! 백그라운드로 가면 브라우저가 화면 갱신을 멈춰서 영상이 끊길 수 있습니다...
- 영상 크기는 이미지의 긴 변 기준 720 / 1080 / 1440px 중에서 고를 수 있습니다 (원본보다 크게 늘리지는 않아요).
